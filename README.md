# 🚀 High-Performance Caching Forward-Proxy

Высокопроизводительный кэширующий прокси-сервер на **.NET 8 (Minimal API)**. 
Изначально разработан для оптимизации работы распределенных систем веб-парсинга (до тысяч одновременных потоков). Устраняет дублирующие запросы к целевым серверам, значительно снижает сетевую нагрузку и ускоряет получение данных.

## 🏗 Архитектурные решения (Under the Hood)

Проект спроектирован с учетом требований к highload-системам и включает защиту от типичных узких мест производительности:

* **Защита от Cache Stampede (Пробой кэша):** Реализован паттерн *Double-check locking* с использованием `ConcurrentDictionary` и легковесных асинхронных блокировок `SemaphoreSlim`. Гарантирует, что при конкурентном доступе сотен парсеров к пустому кэшу, к origin-серверу уйдет строго один сетевой запрос.
* **Защита от утечек LOH (Large Object Heap):** Файлы размером более 5 МБ (или ответы с ошибками) стримятся напрямую клиенту через `CopyToAsync` без сохранения в оперативную память. Это предотвращает фрагментацию кучи и долгие сборки мусора (GC Gen2).
* **Сетевая оптимизация:** Использование `HttpCompletionOption.ResponseHeadersRead` предотвращает выкачивание больших файлов в память до принятия решения о кэшировании.
* **Защита от Socket Exhaustion:** Настроенный пул соединений через `IHttpClientFactory` и `SocketsHttpHandler` (лимиты на `PooledConnectionLifetime` и `MaxConnectionsPerServer`).
* **Прозрачное кэширование трафика:** Полная поддержка сжатия трафика (Gzip/Brotli) и корректного маппинга MIME-типов благодаря сохранению словаря заголовков ответа. Корректная фильтрация внутренних Hop-by-Hop заголовков.

## 📁 Структура проекта

Кодовая база разделена на независимые слои (Clean Architecture подхода):
* `/Models` — структуры данных (например, `CachedItem` для хранения байтов и заголовков).
* `/Utils` — статические утилиты для фильтрации HTTP-заголовков.
* `/Endpoints` — инкапсулированная логика маршрутизации (`ProxyEndpoints.cs`), реализованная через Extension методы для `IEndpointRouteBuilder`.
* `Program.cs` — чистый Composition Root: только DI-контейнер, конфигурация и пайплайн.
